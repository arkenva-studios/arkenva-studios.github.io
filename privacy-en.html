Privacy Policy

Last updated: October 22, 2026. This policy has been drafted for the project's early development stage. It must be reviewed against the implemented data handling practices before public release or live collection of player information.

Data privacy contact: arkenvastudios.contact@gmail.com. Use this address for privacy questions, access and deletion requests.

1. Scope and project

This policy describes the planned handling of data relating to the Update Together website and the potential use of Epic Online Services (EOS) account and multiplayer functions. Arkenva Studios is the name of an independent game development project. No claim of incorporation is intended.

2. This website

This is designed as a static informational website. The site code has no account system, contact forms, ad tracking, analytics scripts, tracking cookies or custom personal-data collection server. This website is prepared for GitHub Pages hosting. GitHub may process technical access logs, such as IP addresses, timestamps and requests, for hosting and security according to its own privacy practices. See the GitHub privacy statement for details.

3. Game data and Epic Online Services

Update Together is not yet generally available. The planned online features may use Epic Online Services. Depending on the actual implementation and user-granted permissions, the following categories may be processed:

  • Epic display name and player/service identifier;
  • Temporary lobby membership, selected game role, readiness and session state;
  • Diagnostic records needed to troubleshoot connection stability or security issues;
  • Online presence or friends information only where enabled in the app and authorized by the player.

These are proposed categories, not claims that every category is already collected. We will revise this policy to match the production configuration and implemented retention before launch. Epic Games' own processing is covered by its separate privacy policy.

4. Purposes and sharing

Data may be used to sign players in, support co-op sessions, synchronize player and role states, troubleshoot technical or security failures, and provide support. Necessary information may be made available to EOS, members of the same game session (e.g., displayed name or role), and the hosting provider selected for the service. Selling player data for advertising or building personalized advertising profiles is not planned.

5. Retention, access and deletion

Temporary session data is intended to be retained only while needed. Before release, we will confirm diagnostic-log retention and deletion processes and whether persistent saves exist, and update this section accordingly. For requests to access, correct, or delete personal data held by the project, contact arkenvastudios.contact@gmail.com. We will reasonably verify requests and respond regarding data under our control. Information retained independently by Epic Games is subject to Epic's own tools and policies.

6. Security and younger players

Our development goal is to limit unnecessary collection and access and never expose authentication secrets in public website files. The game has not been released. Appropriate age-related restrictions, parental consent or other safeguards will be considered and implemented when required before release.

7. Changes and contact

We may update this policy when our online features or actual data practices change. The updated version will be published at this URL. Contact: arkenvastudios.contact@gmail.com.
